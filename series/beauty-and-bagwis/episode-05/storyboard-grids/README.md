## Generation and editing

Use grids as cinematography/choreography guides. For a single-angle take, use the chosen clean panel or separately recreated pose with the neutral young-character reference. Do not ask the model to hold one pose for the entire requested duration. For multi-shot R2V guidance, explicitly ask for one moving cinematic sequence with cuts between specified panels, no literal grid/panel borders/numbers on screen; this is guidance, not guaranteed frame timing or first-frame lock. Preserve actual accepted end state between takes.

Start in movement, keep the force/contact/response legible, cut on movement. The opening01–02 can form a3–5second memory hook with NOON added in editing. Resume memory from03 after present context, no repeated hook. Keep short purposeful cuts, no slow motion or idle guard holds. Let rescue mechanics read before cutting away. No new human powers or explanation of current forearm healing.
